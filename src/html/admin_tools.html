Browser Tools

Everything runs locally in your browser. No files are uploaded to the server.

Image Resizer

Upload an image, set new dimensions, download as PNG.

ProtonHash Checker

Compute the ProtonHash of any file, or of a text/path string (UTF-8 bytes). Matches the hash used by items.dat extra_file.

Hashes the UTF-8 bytes of the string above.

RTTEX to PNG

Upload an uncompressed .rttex file, preview it and download as PNG. RTPACK-compressed files are not supported (zlib not available in-browser).

PNG to RTTEX

Upload a PNG (or any image); it is converted to an uncompressed RGBA .rttex, downloaded automatically, and its ProtonHash is shown (use it for extra_file_hash).

Items.dat Converter

Convert Growtopia items.dat between binary, JSON and text formats, fully in your browser. DAT and JSON round-trip losslessly (all fields). TXT keeps core fields only (id, name, category, rarity, max_amount, texture, texture_hash, extra_file, extra_file_hash); other fields default to 0/empty on TXT import. Large files (~20k items) may take a few seconds.
