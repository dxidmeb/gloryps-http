Roles Editor

How roles work: every command in command_roles.json has a required role NUMBER. A player can use a command only if their rank meets that role number. The role tiers (number to display name) are defined in config.json under BUY_SHOP_CONFIG.shop_roles. Role names may use Growtopia color codes, e.g. `1VIP or `#Moderator.

Role Tiers

Display names for each role tier from config.json (shop_roles). Edit and press Save Tier Names. Only the names are written; the rest of config.json is preserved.
