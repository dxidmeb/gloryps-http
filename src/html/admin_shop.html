Gem Shop Editor

Purchases are data-driven: each button reads database/shop/-<name>.json at buy time, so price and granted items take effect immediately with no rebuild. Button VISIBILITY in the in-game store UI is defined separately in shop_tab() (WorldInfo.h). To make a NEW button visible, add its add_button line there and rebuild the server. Deleting a JSON here disables the purchase but the button stays visible until removed from shop_tab() and rebuilt.
